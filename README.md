# Pro OS

**Pro OS v0.1 — A safer hobby operating system project**

A modern, memory-safe hobby OS written in Rust. Focused on security and correctness from day one.

## Why "safer"?
- Written in **Rust** — eliminates whole classes of memory bugs (buffer overflows, use-after-free, data races) that plague traditional C kernels.
- No undefined behavior by default.
- Clear separation of kernel vs userspace (planned).
- Secure boot / signed kernel concepts built into the design.
- Minimal attack surface in early stages.

## Current Status
This is an early skeleton. It boots (in QEMU) and prints to the screen. Much more is planned.
